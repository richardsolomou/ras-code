# Notifications

RAS Code can tell you when a thread needs you, so you can start work and look away.

Turn notifications on in Settings under **General → Notifications**. In a browser, RAS Code asks
for permission the first time you turn them on. On desktop, notifications come from the operating
system, so they carry the RAS Code icon and arrive even when the window is hidden.

Use **Send test notification** to check that they reach you.

## What you are told about

Each kind can be turned on or off on its own:

- **Agent finished** — a turn completed. When the agent's last message is short, the notification
  shows it.
- **Agent failed** — a turn ended with an error.
- **Approval needed** — the agent is waiting for you to approve an action.
- **Input needed** — the agent asked you a question.
- **Provider fallback** — a thread switched to a fallback provider. Off unless you turn it on.

Selecting a notification brings RAS Code forward and opens the thread.

## Staying quiet

**Only notify when unfocused** keeps RAS Code silent while it is the window you are looking at.
Turn it off to be told about other threads while you work in one of them. Either way, RAS Code
never notifies you about the thread on your screen.

You are only told about things that happen while you are connected. Opening RAS Code after a
period away does not replay the notifications you missed.

**Notification sound** plays a short chime with each notification. Turn it off for silent
notifications.

## Dock badge

On macOS and Linux, the desktop app badges its dock icon with the number of threads waiting for an
approval or an answer. The badge clears as you handle them.

## On your phone

The mobile app has its own notifications and is not affected by these settings.
