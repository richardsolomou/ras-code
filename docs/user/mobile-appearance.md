# Mobile appearance

RAS Code Mobile uses the same appearance as the desktop and web apps. Color is reserved for state and actions, so a glance tells you which threads are working, waiting, or failed.

Text is set in Barlow, with Barlow Semi Condensed in tracked caps for legends.

RAS Code includes one light theme and one dark theme. They apply throughout the app, including code reviews, file previews, the terminal, native headers, and sheets.

To change the color scheme:

1. Open **Settings**.
2. Select **Appearance**.
3. Select **System**, **Light**, or **Dark**.

**System** follows the device appearance automatically. Appearance, text, code, and terminal preferences are stored on the device.
